PyCity

A road-building city simulation for Windows. Zone the city, connect it with roads, keep traffic moving and keep crime in check.

Under the hood, assets are modular, textures load in on their own, and a description parser keeps game text out of the game logic so it can be translated. Version 1.0.1 can also load Lua mods to retune the economy.

Cob

Our own programming language, with an interpreter, a native compiler and a package manager. Programs are short and read top to bottom. Version 0.0.7 adds if, elif and else. This one counts down and says when it is done:

set n = 3
while n > 0:
    if n == 1:
        pop("last one!")
    else:
        pop(n)
    set n = n - 1

Install Cob on Debian or Ubuntu

Cob is one package, csf-cob, that carries every Linux build and keeps the one for your machine. The repository is signed, and sudo apt upgrade will keep Cob up to date.

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://github.com/Cob-Software-Foundation/Cob/releases/download/apt-repo/cob-gpg-public-key.asc | sudo tee /etc/apt/keyrings/csf-cob.asc > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/csf-cob.asc] https://github.com/Cob-Software-Foundation/Cob/releases/download/apt-repo ./" | sudo tee /etc/apt/sources.list.d/csf-cob.list
sudo apt update && sudo apt install csf-cob
