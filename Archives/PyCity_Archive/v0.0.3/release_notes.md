Zoning, camera, save/load, and a little variety in the ground — the biggest update yet.

- Houses now build up real demand over time; factories build up supply. Trucks only run when there's an actual factory-house match, no more random pairs
- Small color-coded bar over every building shows demand (houses) or supply (factories) at a glance
- New "Demand met %" stat tracks how well your network is keeping up
- Map is now much bigger than one screen — pan with arrow keys or WASD
- Save/load added: F5 to save, F9 to load
- Empty tiles now use randomized grass art instead of a flat color background
- Fixed the 32-bit build accidentally linking against the 64-bit toolchain in the "Build Both" script

Still alpha — expect bugs and missing features.
